
Hoshyarsaz 2

Smart Environmental Monitoring and Alert System

Project Overview

Hoshyarsaz 2 is a smart environmental monitoring and alert system designed to continuously monitor environmental conditions and provide early warnings when potentially dangerous conditions are detected.

Main Features
	•	Air quality monitoring
	•	Fire detection
	•	Temperature and humidity monitoring
	•	Atmospheric condition monitoring
	•	Emergency SMS notification
	•	Automatic activation of safety equipment
	•	Semi-industrial physical design
	•	Expandable system architecture

Hardware
	•	Arduino
	•	MQ-135 air quality sensor
	•	DHT11 temperature and humidity sensor
	•	BMP320 atmospheric sensor
	•	OLED display
	•	SIM800L GSM module

Communication

Emergency SMS notification was implemented using the SIM800L GSM module.

My Role

I was responsible for the hardware and physical development of the project, including the electronic components, physical construction, assembly, and implementation.

The programming part was completed by another team member.

Prototype

A physical prototype was designed and built with a custom semi-industrial enclosure.
